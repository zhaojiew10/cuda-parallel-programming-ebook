# CUDA 并行编程

一套以完整书面文字组织的中文 CUDA 教程。原课程的 83 个主题按知识关联合并为 **6 个部分、26 章**，避免按视频逐讲拆分造成的重复与割裂。

## 在线阅读

**[https://zhaojiew10.github.io/cuda-parallel-programming-ebook/](https://zhaojiew10.github.io/cuda-parallel-programming-ebook/)**

网站提供章节目录、站内搜索、代码高亮，以及课件页、视频帧和 SVG 示意图。

## 内容结构

1. **并行计算思维与 CUDA 程序骨架**：并行与异构系统、开发环境、线程索引、向量加法、结果验证、错误处理和计时。
2. **GPU 执行模型与归约优化**：SM、Warp、分化、占用率、树形归约、展开和动态并行。
3. **内存层次、全局访问与片上优化**：主机内存策略、合并访问、AoS/SoA、矩阵转置、共享内存、Shuffle 和分层归约。
4. **异步流水线：流、事件与依赖**：异步复制、重叠执行、默认流、同步和事件依赖。
5. **数值、原子操作与扫描**：浮点精度、数学 intrinsic、原子更新、块内与跨块扫描、流压缩。
6. **CUDA 图像处理基础与 OpenCV 环境**：图像形成、视觉感知、缓冲区、核函数和环境配置。
