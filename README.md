# CUDA 并行编程

一套以完整书面文字组织的中文 CUDA 教程。原课程的 83 个主题按知识关联合并为 **4 个部分、26 章**，避免按视频逐讲拆分造成的重复与割裂。

## 在线阅读

**[https://zhaojiew10.github.io/cuda-parallel-programming-ebook/](https://zhaojiew10.github.io/cuda-parallel-programming-ebook/)**

网站提供章节目录、站内搜索、代码高亮，以及课件页、视频帧和 SVG 示意图。

## 内容结构

1. **CUDA 入门与程序骨架**：并行与异构系统、开发环境、线程索引、向量加法、结果验证、错误处理和计时。
2. **理解 GPU 执行与归约优化**：SM、Warp、分化、占用率、树形归约、展开和动态并行。
3. **优化内存访问与片上通信**：主机内存策略、合并访问、矩阵转置、共享内存、Shuffle 和分层归约。
4. **综合并行实践**：异步流水线、浮点精度、原子操作、扫描、流压缩和图像处理。

## 仓库内容

仓库仅包含公开发布的电子书正文、精选配图和网站配置，不包含原课程视频、字幕、课件源文件、候选图片或内部工作材料。

书中代码用于解释核心原理。实际开发时，应结合目标 GPU、CUDA 版本和 NVIDIA 官方文档完成编译、正确性检查及性能验证。
