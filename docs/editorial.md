# 编写说明与版本提示

## 编写与合并原则

本书依据 **Mastering Parallel Programming with CUDA Platform** 的课程内容进行中文书面精编，网站形式参考 [zhaojiew10/cuda-ebook](https://github.com/zhaojiew10/cuda-ebook)。原课程主题被重组为 8 个部分、26 章，每章对应一个概念或实验闭环。

合并遵循以下原则：

- 将线程组织、索引实验和边界检查放进连续案例；
- 将数组求和、验证、错误处理和计时组织为完整工程流程；
- 用归约串联执行模型、展开、共享内存、Shuffle 和原子操作；
- 用矩阵转置串联全局访问、数据布局、Bank、填充和分块优化；
- 将流、默认流和事件组织为异步时间线实验；
- 将重复总结改写为相应章末清单，不再独立占章。

正文不保留字幕序号、时间戳和课堂口语。合并不等于删减：重复内容只讲一次，算法前提、同步条件和实验约束仍应保留。

## 代码与实验边界

书中代码用于解释核心原理，并尽量标明执行配置、共享内存容量、线程束掩码和缓冲区生命周期等必要前提。部分索引与算法经过枚举或模拟检查，但这不能替代目标设备上的编译和运行验证。

将示例用于实际项目时，应补齐完整工程、错误处理与资源管理，并根据目标环境执行正确性测试、`compute-sanitizer` 和性能分析。课程中的性能数字和软件界面属于特定历史环境，不应直接视为当前设备的预期结果。

## 配图来源

本书配图来自课程课件、课程视频画面和自绘 SVG：

- 概念图、公式图和算法图优先采用清晰的课件页面；
- 软件界面、终端输出、性能分析器和真实图像效果保留原始视频证据；
- 线程层次、归约、内存路径、流时间线、扫描和图像 Halo 等抽象关系使用 SVG 辅助说明。

旧版工具、安装界面和性能结果均按历史环境理解。SVG 不用于冒充真实性能数据或软件输出。

## CUDA 版本提示

课程环境包含旧版 CUDA Toolkit、CUDA Samples、Visual Studio 和 `nvprof`。阅读时应注意：

- 安装步骤、驱动要求和编译器兼容性会随 CUDA 版本变化。
- `nvprof` 的分析流程可迁移到 Nsight Systems 和 Nsight Compute，但命令和指标不能机械替换。
- 设备限制、共享内存容量和计算吞吐应通过目标设备属性与官方文档确认。
- 默认流、动态并行、统一内存和线程束同步具有具体版本语义，不应依赖旧经验猜测。
- 性能结果与 GPU、数据规模、数据类型和编译选项密切相关，需要在目标环境重新测量。

官方资料：

- [NVIDIA CUDA 文档](https://docs.nvidia.com/cuda/)
- [NVIDIA CUDA Samples](https://github.com/NVIDIA/cuda-samples)
- [NVIDIA Nsight 工具](https://developer.nvidia.com/tools-overview)
