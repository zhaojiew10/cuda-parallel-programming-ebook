# 阅读与实践指南

## 如何使用本书

本书按照 6 个部分组织，将原 83 讲合并为 26 章。每章围绕一个概念或实验闭环展开，以完整书面文字解释原理，通过公式、代码和配图说明实现。正文不依赖原视频时间点，可以独立按顺序阅读，也可以通过目录和搜索按主题查阅。正文中的**粗体**用于标记关键概念、核心结论和易错点。

推荐阅读方式如下：

- **入门阶段**：依次阅读第 1—7 章，完成线程索引、向量加法、错误检查和设备计时。
- **执行模型与优化**：阅读第 8—12 章，将线程束、占用率和归约放在同一性能框架中理解。
- **内存与共享内存**：阅读第 13—19 章，对比直接实现和优化实现的访问路径。
- **异步并发**：阅读第 20—21 章，结合时间线理解流、事件和重叠执行。
- **指令与数值**：阅读第 22 章，理解浮点精度、intrinsic 和原子竞争。
- **并行算法**：阅读第 23—24 章，重点掌握扫描的阶段划分和跨块偏移传播。
- **图像处理**：阅读第 25—26 章，将缓冲区布局、视觉原理和 OpenCV 环境联系起来。

## 实践原则

每章实验都应回答三个问题：程序是否正确，性能是否改善，结论能否复现。能够编译和运行只说明环境基本可用，并不能证明索引、同步和数值结果正确。

建议为每个优化保留独立基准版本，固定输入、编译选项和测试环境。修改后先通过正确性检查，再进行预热和多次测量。性能报告应包含 GPU、CUDA 版本、数据规模和计时区间。

## 如何使用代码示例

书中代码用于突出核心原理，通常省略完整的命令行参数处理、资源 RAII 封装和工程构建脚本。将其整合到项目时，应补齐以下事项：

1. 检查 CUDA API 返回值、核函数启动错误和同步错误。
2. 根据数据规模验证网格覆盖与边界条件。
3. 明确主机和设备缓冲区的生命周期。
4. 使用独立主机参考实现检查结果，浮点算法采用合理误差范围。
5. 根据当前 CUDA 文档确认 intrinsic、动态并行、默认流和线程束同步语义。

## 版本差异

课程涉及 CUDA Toolkit 10.0、CUDA Samples 9.1 和 `nvprof` 等旧版环境。书中保留其背后的方法，但不把旧版命令描述为当前唯一选择。性能分析可以分别使用 Nsight Systems 观察时间线、Nsight Compute 分析核函数，具体命令和指标以所用版本为准。

## 阅读检查清单

完成一章后，可以尝试回答以下问题：

- 本章解决了什么问题，为什么串行方法不足以满足需求？
- 线程、数据和内存地址之间如何对应？
- 哪些同步和边界条件是正确性所必需的？
- 性能结论来自理论分析还是实际测量，测量范围是否明确？
- 示例在当前 CUDA 版本与目标 GPU 上是否仍然适用？
